# 🎮 EscapeMine

**Uma aventura subterrânea. Uma luta pela sobrevivência. Uma última xícara de café. ☕**

EscapeMine é um jogo 2D desenvolvido com a **Godot Engine 4.6.1**, que combina combate, exploração e sobrevivência em um ambiente subterrâneo. Ajude Lucas a enfrentar os perigos de uma mina misteriosa, encontrar a saída e finalmente voltar para casa.

</p>

## Lore 

Lucas é um engenheiro industrial que levava uma vida perfeitamente comum. Em mais um dia de trabalho, tudo parecia seguir a rotina habitual, até que um acidente inesperado o fez cair nas profundezas de uma mina misteriosa.

Agora, perdido em um labirinto subterrâneo e cercado por criaturas que habitam a escuridão, Lucas precisa reunir coragem para enfrentar os perigos que surgem em seu caminho.

Entre monstros, passagens desconhecidas e desafios cada vez maiores, seu objetivo é simples: sobreviver, encontrar a saída e voltar para casa.

Afinal, depois de um dia desses, tudo o que Lucas merece é uma boa xícara de *café*. ☕

**Você consegue ajudá-lo a escapar?**

## 🏗️ Padrões de projeto

O EscapeMine utiliza padrões de projeto para organizar responsabilidades, favorecer o reaproveitamento de código e facilitar a manutenção e a evolução dos sistemas do jogo.

| Padrão | Finalidade |
|---|---|
| **Factory** | Centraliza a criação e instanciação de objetos. |
| **Builder** | Organiza a construção de objetos ou configurações complexas. |
| **Prototype** | Permite criar objetos a partir de protótipos existentes. |
| **Singleton** | Disponibiliza uma instância compartilhada para sistemas globais. |
| **MVC (Model–View–Controller)** | Separa as responsabilidades de dados, apresentação e controle. |
| **Adapter** | Permite a integração entre interfaces incompatíveis. |
| **Composite** | Organiza objetos individuais e grupos por meio de uma estrutura comum. |
| **Decorator** | Adiciona responsabilidades ou comportamentos sem modificar diretamente a estrutura original. |
| **Facade** | Simplifica o acesso a subsistemas por meio de uma interface unificada. |
| **Proxy** | Controla ou intermedeia o acesso a outro objeto. |
| **Command** | Encapsula ações em objetos independentes. |
| **Observer** | Permite a comunicação entre objetos por meio de eventos e notificações. |
| **State** | Organiza o comportamento de um objeto de acordo com seu estado atual. |
| **Strategy** | Encapsula algoritmos ou comportamentos intercambiáveis. |

A aplicação desses padrões contribui para uma arquitetura mais organizada e demonstra o uso de conceitos de orientação a objetos e boas práticas de desenvolvimento de software.
